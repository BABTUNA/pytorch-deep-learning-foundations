# PyTorch Deep Learning Foundations

Notes and small exercises from a 2023 introduction to deep learning with
PyTorch. The course starts with tensors and autograd, then builds reusable data
and training code before moving on to MLP and CNN experiments.

## Topics

- tensor operations and broadcasting
- automatic differentiation
- datasets and data loaders
- training and validation loops
- multilayer perceptrons and convolutional networks
- regularization, checkpoints, and inference

Examples use Python 3.10, PyTorch 2.0, torchvision 0.15, and JupyterLab 3.6.
